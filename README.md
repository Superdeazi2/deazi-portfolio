## Как скачать и запустить проект

Склонировать проект:

```bash
git clone https://gitlab.com/Deazi/deazi-portfolio.git
```

Перейти в папку проекта:

```bash
cd deazi-portfolio
```

Установить зависимости:

```bash
npm install
```

Запустить проект локально:

```bash
npm run dev
```

После запуска Vite покажет локальный адрес, обычно:

```bash
http://localhost:5173
```

Собрать проект:

```bash
npm run build
```


## Структура проекта

Основная логика находится в папке `src`.

Данные профиля и опыта работы вынесены отдельно, чтобы их было удобно редактировать без копирования одинаковых блоков разметки.

Опыт работы редактируется через массив данных, а карточки на сайте строятся автоматически через компоненты.
