## Новый проект

### Гротеск | Тестовое задание

Выполнил тестовое для студии «Гротеск»: по макету Figma сделал корзину, оформление заказа и страницу успеха

- Адаптировал страницы под 414, 768, 1366 и 1920 px
- Подключил товары из API задания, изменение количества с учётом остатка и удаление товаров
- Добавил расчёт суммы и скидки, промокод GROWTASK2026 и удаление выбранных товаров
- Сделал сохранение корзины, маску телефона и проверку полей формы
- Собрал данные заказа в массив и вывел в консоль, как требовалось в задании

**HTML · CSS · JavaScript · Vite**
