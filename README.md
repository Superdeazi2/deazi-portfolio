# Deazi – Личная страница "Обо мне"

Привет! Меня зовут Михаил, я Frontend-разработчик.  
Эта небольшая страница создана для демонстрации того, как я работаю с фронтендом. Сайт собран с помощью **Vite** и стилизован через **Tailwind CSS**.

---

## О проекте

На этой странице я показываю:

- Адаптивную верстку для разных устройств;
- Простые анимации и интерактивные элементы;
- Компонентный подход к созданию UI.

Цель проекта — показать мои навыки в верстке, работе с CSS-фреймворками и создании удобного интерфейса.

---

## Технологии

- HTML5, CSS3, JavaScript
- Tailwind CSS
- Vite
- Git для контроля версий
